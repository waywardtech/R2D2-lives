# Spatial Agent Protocol changelog

## 0.1.0-draft - 2026-08-11

- Define independent Mobile Agent and Spatial Provider roles.
- Define HTTPS JSON, SSE, and artifact MVP transport profile.
- Add capability/session negotiation, high-level command lifecycle, observations, localization, map revisions, route advisories, and events.
- Require SI units, right-handed named frames, UTC plus monotonic clocks, clock uncertainty, pose uncertainty/provenance, idempotency, and content hashes.
- Add Agent and Spatial Provider OpenAPI drafts, common JSON Schema, AsyncAPI event definition, and canonical examples.

The protocol remains pre-1.0 until simulator conformance, R2 MVP integration stubs, BSM simulation, and the first live R2-BSM integration have validated the model.
